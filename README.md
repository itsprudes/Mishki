# Мишки крутышки — веб-компоненты

Реализация страниц и компонентов из макета «Мишки крутышки».

## Механики

- [`partybus/index.html`](partybus/index.html) — **Патибас**: автобус-карусель
  с 17 окнами. В окнах сидят Мишки-крутышки; часть окон — в состоянии
  «Найди нового Мишку» (заблокированы). Автобус листается стрелками,
  адаптив desktop / tablet / mobile.
- [`cards/cards.html`](cards/cards.html) — три типа карточек в двух размерах
  на фоне из макета. Разбор в [`cards/README.md`](cards/README.md).

Подробности по Патибасу — в [`partybus/README.md`](partybus/README.md).
