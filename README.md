# Мишки крутышки — веб-компоненты

Реализация карточек и фона из макета «Мишки крутышки».

Страница с примерами: [`web/cards.html`](web/cards.html) — три типа карточек
в двух размерах на фоне из макета.

Разбор компонентов, размеры, ассеты и расхождения выгрузки «Copy as CSS»
с тем, что на самом деле задано в макете — в [`web/README.md`](web/README.md).
