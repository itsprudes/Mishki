# Мишки крутышки — веб-компоненты

Реализация карточек и фона из макета
[«Мишки крутышки»](https://www.figma.com/design/j19D4cAsBdkoqxWBs3sDlO/).

Демо и код — в папке [`web/`](web/):

| файл                    | что это                                                        |
| ----------------------- | -------------------------------------------------------------- |
| `index.html`            | демо всех трёх типов карточек на космическом фоне               |
| `starfield.js`          | процедурный фон «метеорный дождь» на canvas                     |
| `imgcard-compare.html`  | карточка с изображением: правильная и ошибочная реализация рядом |
| `backdrop-demo.html`    | где виден `backdrop-filter`                                     |
| `img/`                  | подложки карточек из макета                                     |

Подробности по каждому компоненту, разбор расхождений с выгрузкой
«Copy as CSS» из Figma и замеры — в [`web/README.md`](web/README.md).
