# Патибас

Автобус-карусель с Мишками-крутышками. Собрано по узлам макета
`5856-505074` (desktop), `5856-505081` (tablet), `5856-505088` (mobile),
компонент автобуса `5454-167939`, состояния окна `4405-1662875`.

Открыть: `index.html`.

## Устройство

Стеклянная плашка (backdrop-filter, градиент к `#0a064c`) на космическом
фоне. Внутри: логотип «ПАТИБАС», подзаголовок, автобус-карусель и контролы.

### Автобус и окна

Автобус — один блок фиксированного размера в координатах макета
(3374 × 640), масштабируется под брейкпоинт переменной `--bus-scale`
и листается в окне-карусели (`overflow:hidden` + `translateX`). За счёт
этого адаптив получается сам: на узком экране виден меньший кусок крупнее,
как в макете.

Фон автобуса (`img/bus.png`) — пустой автобус: окна тёмные, диско-шар,
дверь с шариками и звёзды уже запечены. Он позиционирован кропом из макета
(картинка масштабирована и смещена внутри видимой области 3335 × 640),
чтобы координаты окон совпали.

Окна (17 штук) строятся скриптом из массива `WINDOWS` — координаты каждого
окна взяты из Figma codegen. Маска окна в макете оказалась обычным
прямоугольником (`M0 0H199V160…`), поэтому окно — это просто
`overflow:hidden`-проём, внутрь которого посажена фигурка мишки; проём
обрезает её по рамке.

### Состояния окна

Каждое окно в массиве `WINDOWS` имеет поле `bear`:

- номер (`'01'`…`'16'`, `'00'` — золотой Boss) — в окне сидит эта фигурка;
- `null` — окно в состоянии **«Найди нового Мишку»**: затемнение, замок
  в правом верхнем углу и подпись по центру (как в узле `4405-1662875`).

Сейчас заблокированы 5 окон вразброс — меняется правкой массива.

### Карусель

Стрелки (`#prev` / `#next`) двигают дорожку на 80% ширины видимой области;
крайние положения ограничены, неактивная стрелка гаснет. Пересчитывается
на resize.

## Ассеты (`img/`)

| файл                | что это                                            |
| ------------------- | -------------------------------------------------- |
| `space-bg.png`      | космический фон страницы (тот же, что в `cards/`)   |
| `bus.png`           | автобус без мишек, 3552 × 1184                      |
| `logo.png`          | логотип «ПАТИБАС», квадратный PNG (кропается CSS)   |
| `bears/bear-00..16` | 17 фигурок мишек (00 — золотой Boss)                |
| `btn-bg.png`        | подложка активной кнопки-стрелки                    |
| `chevron-l/r.svg`   | иконки стрелок                                      |

Все ассеты выгружены из макета. Логотип — квадратный PNG с текстом в центре;
контейнер `.logo` кропает прозрачные поля (пропорции текста замерены:
79% ширины, центр совпадает с центром файла).

Шрифт макета — X5 Sans; не поставляется с репозиторием, стоит первым в
`font-family` с системным фолбэком.
