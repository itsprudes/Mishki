# Патибас

Автобус-карусель с Мишками-крутышками. Собрано по узлам макета
`5856-505074` (desktop), `5856-505081` (tablet), `5856-505088` (mobile),
компонент автобуса `5454-167939`, состояния окна `4405-1662875`.

Открыть: `index.html`.

## Устройство

Стеклянная плашка (backdrop-filter, градиент к `#0a064c`) на космическом
фоне. Внутри: логотип «ПАТИБАС», подзаголовок, автобус-карусель и контролы.

### Автобус и окна

Автобус — один блок фиксированного размера в координатах макета
(3374 × 640), масштабируется под брейкпоинт переменной `--bus-scale`
и листается в окне-карусели (`overflow:hidden` + `translateX`). За счёт
этого адаптив получается сам: на узком экране виден меньший кусок крупнее,
как в макете.

Фон автобуса (`img/bus.png`) — пустой автобус: окна тёмные, диско-шар,
дверь с шариками и звёзды уже запечены. Он позиционирован кропом из макета
(картинка масштабирована и смещена внутри видимой области 3335 × 640),
чтобы координаты окон совпали.

Окна (17 штук) строятся скриптом из массива `WINDOWS` — координаты каждого
окна взяты из Figma codegen.

Видимую область мишки задаёт не `overflow` окна, а **маска-прямоугольник
180×153 в позиции (29, 19)** на самой фигурке (как `mask-no-clip` в макете).
Благодаря этому макушка и петелька мишки **выступают над верхним краем окна
и не срезаются** — окно обрезает только бока и низ. Фигурка — контейнер
240×240, посаженный `bottom: -68px` и центрированный по окну.

### Hover

При наведении на окно мишка приподнимается: `bottom` −68 → −60px, а маска
съезжает вниз (позиция 19 → 27) — фигурка «выглядывает выше». Значения из
состояния Hover компонента (узел `4405-1662875`), переход плавный.

### Состояния окна

Каждое окно в массиве `WINDOWS` имеет поле `bear`:

- номер (`'01'`…`'16'`, `'00'` — золотой Boss) — в окне сидит эта фигурка;
- `null` — окно в состоянии **«Найди нового Мишку»**: скруглённая плашка
  `rgba(0,0,0,.3)` со стеклом (`backdrop-blur 8`), замок 32px в правом
  верхнем углу и подпись 18px снизу (как в узле `4405-1662875`).

Сейчас заблокированы 5 окон вразброс — меняется правкой массива.

### Карусель и кнопки

Листается тремя способами: стрелками (`#prev`/`#next`, шаг 80% видимой
ширины), **перетаскиванием мышью или пальцем** и **колесом**. Крайние
положения ограничены (`clamp`), на краю кнопка переходит в Disabled.
Во время drag/колеса анимация выключается (`.no-anim`), после — плавная.
Клик по мишке после перетаскивания подавляется (порог 6px), картинки
`draggable=false`.

Автобус выходит на всю ширину плашки (карусель бьётся за её горизонтальный
padding через `--party-px`) и **обрезается самой плашкой** (`.party`
`overflow:clip` + скругление), а не отдельным контейнером.

Кнопки — компонент `ButtonMetal` (узел `4186-136067`), размер L 56, все
состояния:

- **Default** — серебряный хром-диск (`img/btn-bg.png`, экспорт грани кнопки
  из макета) + стрелка;
- **Hover** — поверх диска затемнение `rgba(0,0,0,.16)`;
- **Press** (`:active`) — затемнение `rgba(0,0,0,.24)`;
- **Focus** (`:focus-visible`) — двойная обводка: внутренняя чёрная 2px,
  внешняя белая 4px;
- **Disabled** — без хрома, плоский фон `white/20`, стрелка `white/50`.

Иконки-стрелки заданы через CSS-маску (`ctrl__icon` — маска из SVG,
`background` = цвет), поэтому цвет управляется состоянием: тёмная `#2C323C`
на металле и `white/50` в Disabled — как в компоненте.

Хром-грань взята как PNG-экспорт узла кнопки: сам ассет-текстура в макете
(`Nano…181502171`) — почти пустой блик 4 КБ, серебро создаётся заливкой,
которой нет в codegen, поэтому надёжнее экспортировать готовую грань.

## Ассеты (`img/`)

| файл                | что это                                            |
| ------------------- | -------------------------------------------------- |
| `space-bg.png`      | космический фон страницы (тот же, что в `cards/`)   |
| `bus.png`           | автобус без мишек, 3552 × 1184                      |
| `logo.png`          | логотип «ПАТИБАС», квадратный PNG (кропается CSS)   |
| `bears/bear-00..16` | 17 фигурок мишек (00 — золотой Boss)                |
| `btn-bg.png`        | подложка активной кнопки-стрелки                    |
| `chevron-l/r.svg`   | иконки стрелок                                      |

Все ассеты выгружены из макета. Логотип — квадратный PNG с текстом в центре;
контейнер `.logo` кропает прозрачные поля (пропорции текста замерены:
79% ширины, центр совпадает с центром файла).

Шрифт макета — X5 Sans; не поставляется с репозиторием, стоит первым в
`font-family` с системным фолбэком.
